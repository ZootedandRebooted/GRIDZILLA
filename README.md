# GRIDZILLA 1.2

## A monster in your machine.

GRIDZILLA expands the MPC Sample with virtual instruments, editable MIDI, a song arranger, a live mixer and effect automation. It runs from SD without flashing Akai firmware.

**[Download GRIDZILLA 1.2](https://www.thesoundfactorynj.com/gridzilla)**

[GitHub release](https://github.com/ZootedandRebooted/GRIDZILLA/releases/tag/v1.2)

## What’s included

- **GRIDZILLA-1.2.zip** — the `autorun` and `WaveGrid` installation folders, PDF guide and video.
- **GRIDZILLA-1.2-User-Guide.pdf** — a 23-page illustrated walkthrough covering installation, controls, recording, editing, arranging, mixing and automation.
- **GRIDZILLA-1.2-Video.mov** — the video walkthrough.

## Make the whole track

- Play virtual instruments and one-pad chords, from triads through 13ths.
- Edit notes in the pad grid or Melodic piano roll. Use recording SNAP to place new notes on the selected grid.
- Build songs from sequences in Arranger.
- Mix while the song plays, with pad faders, MUTE, SOLO, meters and a MASTER channel.
- Add EQ, Saturation, Delay, Reverb, Limiter, compressor and Flex Beat inserts.
- Record effect automation or place individual Flex Beat ON/OFF points with Undo.

## Install

1. Save your project and back up your SD card.
2. Power off the MPC before removing the card.
3. Unzip the download and follow the PDF’s first-install or update steps. Keep your existing projects and samples.
4. Safely eject the card, put it back in the MPC and start up.

Stem export is not included in this release.
